## Why LaunchKit?

Your AI agent already knows how to ship with LaunchKit. Every file, pattern, and convention is tuned so Claude Code, Cursor, Windsurf, and Antigravity navigate, refactor, and add features from day one — no hand-holding required.

<AccordionGroup>
  <Accordion title="What's included?">
    - **Auth** — Clerk (email, social, magic link, MFA, organizations)
    - **Billing** — Stripe Checkout (Apple Pay, Google Pay, Link)
    - **Database** — Neon Postgres + Drizzle ORM + pgvector
    - **AI** — Vercel AI SDK, 11 providers, streaming chat, image gen
    - **Teams** — Multi-tenant orgs, role-based access, invites
    - **Email** — React Email + Resend (welcome, billing, drip)
    - **Admin** — SuperAdmin panel, revenue metrics, feature flags
    - **Plugins** — Feedback, waitlist, testimonials, roadmap (8 plugins)
    - **AI IDE Rules** — CLAUDE.md, .cursorrules, AGENTS.md, .windsurfrules, and more
  </Accordion>
  <Accordion title="Who is it for?">
    LaunchKit targets **technical founders** who are already using AI coding tools like Claude Code, Codex, Cursor, Windsurf, or Antigravity. These are not beginners — they're developers who want production-ready infrastructure pre-wired so they can focus on building their product's unique value.
  </Accordion>
  <Accordion title="How is it different from MakerKit or ShipFast?">
    LaunchKit ships with **AI-native developer experience** built in — CLAUDE.md, .cursorrules, AGENTS.md, and rules files for every major AI IDE. The repo is designed to be navigated by AI agents without hallucinations. No other boilerplate does this.
  </Accordion>
</AccordionGroup>
