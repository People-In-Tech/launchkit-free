# AI Tools

Most SaaS boilerplates ignore the AI. LaunchKit is built specifically for developers who code with Claude Code and Cursor. Four files give your AI everything it needs — stack, patterns, schema, conventions — before it writes a single line of code.

---

## The four files

### `CLAUDE.md`

Loaded automatically by Claude Code when you open the project. Covers:
- Monorepo structure and how packages relate
- The exact Drizzle query patterns to use (and what to avoid)
- Component conventions: Server Components vs Client Components, when to use each
- Styling rules: Tailwind + shadcn/ui only, no custom CSS
- Hard rules: no `any` types, no raw SQL, always validate with Zod

Claude reads this on startup. You don't have to explain any of this yourself.

### `.cursorrules`

The Cursor IDE equivalent of `CLAUDE.md`. Same content, formatted for Cursor's context loading. Open any file in Cursor and it has full project context automatically.

### `AGENTS.md`

600+ line architecture reference. The most detailed of the four. Covers:
- Where every important file lives and why
- The full database schema with relationships
- How auth flows from Clerk → middleware → database
- How billing flows from Stripe → webhook → database
- How to add a new feature correctly end-to-end
- Common mistakes and how to avoid them

**Use this for complex tasks.** Start your prompt with *"Read AGENTS.md first, then..."*

## Copy-paste prompts

**New feature from scratch:**
```
Read AGENTS.md before starting.

I want to add [feature name]. Here's what it needs to do:
- [requirement 1]
- [requirement 2]
- [requirement 3]

Start by creating the database table in packages/database/src/schema/,
then push the schema with pnpm db:push, then build the feature.
```

**Adding a new page:**
```
Add a dashboard page at /dashboard/[slug] that shows [description].
Follow the exact same structure as apps/web/app/dashboard/page.tsx.
Use Server Components for data fetching. If there's a form, use a Server Action.
```

**Debugging an error:**
```
I'm getting this error: [paste error]

The relevant files are:
- [file 1 path]
- [file 2 path]

Don't change anything else. Just fix this specific issue.
```

**Customizing the design:**
```
Update apps/web/app/globals.css to change the primary color to [hex color].
Convert it to HSL format. Update both :root and .dark sections.
Don't change anything else.
```
