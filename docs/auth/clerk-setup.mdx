## 1. Create a Clerk Application

1. Go to [clerk.com](https://clerk.com) and create an account
2. Create a new application
3. Choose your sign-in methods (Email, Google, GitHub recommended)

## 2. Copy API Keys

From your Clerk Dashboard → API Keys:

```bash
NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_live_...
CLERK_SECRET_KEY=sk_live_...
```

## 3. Configure Webhooks

LaunchKit syncs Clerk user and org events to your Neon database via webhooks.

1. Go to **Clerk Dashboard → Webhooks**
2. Add endpoint: `https://yourdomain.com/api/webhooks/clerk`
3. Subscribe to these events:
   - `user.created`
   - `user.updated`
   - `user.deleted`
   - `organization.created`
   - `organizationMembership.created`
   - `organizationMembership.deleted`

4. Copy the **Signing Secret** to your env:
```bash
CLERK_WEBHOOK_SECRET=whsec_...
```

## 4. Enable Organizations

For Teams features (multi-tenant), enable Organizations in Clerk:

1. Go to **Clerk Dashboard → Organizations**
2. Enable Organizations
3. Set membership permissions as needed

## 5. Social Providers (Optional)

To add Google / GitHub login:

1. Go to **Clerk Dashboard → Social Connections**
2. Enable the providers you want
3. Add OAuth credentials from each provider

## Custom Sign-In UI

The sign-in and sign-up pages live at:
- `apps/web/app/auth/sign-in/page.tsx`
- `apps/web/app/auth/sign-up/page.tsx`

They use Clerk's pre-built `<SignIn />` and `<SignUp />` components. Customize appearance via Clerk's appearance prop or their Dashboard theme editor.

## Protecting Pages

```typescript
// Server Component — redirect to sign-in if not authenticated
import { auth } from "@clerk/nextjs/server";
import { redirect } from "next/navigation";

export default async function ProtectedPage() {
  const { userId } = await auth();
  if (!userId) redirect("/auth/sign-in");
  // ...
}
```
